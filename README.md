# Notulen AI

Self-hosted, Indonesian-first meeting transcription and AI notetaking SaaS.

The production design uses Laravel for multi-tenant business workflows and independent Python workers for audio/AI processing. See the implementation branch and pull requests for the current scaffold, status, and deployment instructions.

> Security: never commit `.env`, API keys, customer recordings, or transcripts.

## Project status

Initial repository bootstrap. Features are added incrementally through reviewed pull requests; this README does not claim production readiness.
